# Generated catalogs

This directory contains generated catalog surfaces for the documentation system.

## Current catalog contract

- `docs-catalog.json` is the maintained source catalog for winning documentation roots.
- `../../docs/catalog.json` is the derived mirror used as the front-door catalog surface inside `docs/`.

Do not hand-edit generated outputs here and treat them as independent authority. Update the canonical documentation change, update the maintained source catalog in the same diff when required, and regenerate the derived mirror.
