# Documentation Standards
_Audience: Contributors and reviewers • Owner: Platform Team • Last verified: 2026-03-09 • Status: canonical_

This directory contains canonical standards for how documentation is authored, classified, governed, and verified in this repository.

## Use this directory for

- docs/specs boundary rules
- evidence and status reporting standards
- documentation structure and style standards
- contributor-facing documentation governance material

## Do not use this directory for

- ADR decision records, which belong in `docs/adr/**`
- living architecture law, which belongs in `docs/concepts/architecture/**`
- runtime operator procedures, which belong in `docs/ops/**`
