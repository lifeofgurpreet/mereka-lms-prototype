# Mereka LMS — Interactive Prototype

A clickable prototype of the Mereka Learning Management System.

## What's inside

- **Discover** page with course catalog and filters
- **Course detail** page with reviews, FAQs, promo codes, sample certificate
- **Unit player** with video/doc/quiz/discussion/assignment content types
- **Studio** with multi-course management, outline editor, and content library
- **Dashboard, Wishlist, Checkout, Settings, Profile** and more

## Running locally

Just open `index.html` in any modern browser — no build step, no server required.

## Live preview

Once GitHub Pages is enabled on this repo, the prototype will be available at:
`https://<your-username>.github.io/<repo-name>/`
