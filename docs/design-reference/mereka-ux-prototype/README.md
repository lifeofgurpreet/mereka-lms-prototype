# Mereka LMS — UX Prototype (Design Reference)

**Source repo (original):** `faizmereka/mereka-lms-prototype` (single-file HTML prototype)
**Integrated here:** 2026-04-24
**Owner:** Faiz Fadhillah
**Status:** Design reference — NOT a shipping artifact. Informs MFE slot + theme work in this repo.

---

## What this is

A self-contained single-file HTML application (`index.html`, ~423 KB, ~7,300 lines) that models the full Mereka Academy learner + Studio experience. Uses a `goto(pageId)` router, inline CSS with brand tokens, and hardcoded demo data to demonstrate interaction flows end-to-end without a backend.

## What it's for in this repo

This prototype serves as the **design source of truth** driving MFE slot + theme customization in the production Open edX deployment at `academyv2.mereka.io`. For each visual element or flow in this prototype, there's a corresponding implementation target in one of:

- `infrastructure/tutor/brand-mereka/paragon/` — design tokens (colors, typography, radii)
- `infrastructure/tutor/brand-mereka/tokens/src/` — DTCG source tokens
- `infrastructure/tutor/themes/mereka/mfe/scss/` — MFE SCSS per-surface partials
- `infrastructure/tutor/themes/mereka/lms/` + `cms/` — legacy Django theme
- `infrastructure/tutor/plugins/mereka_lms_mfe_slots.py` — 63 MFE plugin slots
- `infrastructure/tutor/plugins/_mereka_lms/mfe_runtime_definitions.js` — JSX slot widget definitions

## How to view it

Open `index.html` in any modern browser. No build step, no server required.

Or deploy a copy: the prototype was originally hosted via Netlify from a standalone repo. It lives here now as a static artifact.

## Design tokens already in production theme

All brand values from the prototype are already wired in `infrastructure/tutor/brand-mereka/paragon/tokens.json`:

- `color.primary` = `#AB3B78` (Academy Plum)
- `color.secondary` = `#237072` (Teal)
- `color.accent-a` = `#94D1E4` (Sky)
- Brand gradient via `--mereka-mfe-gradient` (plum → teal → blue, 120°)
- `fontFamily.sans-serif` = Poppins + Lato stack
- Button border-radius pill 9999px
