## What is NOT yet proven — browser-capable next step

### Waffle flag state

Per prior slice-63 retraction evidence: only `learner_home_*` flags exist in DB (`learner_home.redirect_to_microfrontend`, `learner_home_mfe.enabled`). No `courseware_*` or `CourseMicroFrontendFlag` entry found. Probe commands:

```bash
kubectl --context rke2-nonprod -n mereka-lms-dev exec deploy/lms -- \
  python manage.py lms waffle_flag --list 2>&1 | grep -iE "courseware|learner|mfe"
```

**Conclusion**: courseware MFE routing gate is likely NOT a Django waffle flag. It's in upstream `frontend-app-learning` JS OR auth/CSP blocking the MFE shell bootstrap.

### Error boundary source

The Learning MFE error boundary fires on D-03/D-04/D-05 paths. What JS error trips it? Needs browser DevTools network + console:

```
URL: https://apps.academyv2.mereka.dev/learning/course/course-v1:MEREKA+MCT1-EN+course/home
Expected: lesson renders
Observed (prior testing): generic error boundary — no stack trace captured yet
```

Browser-capable agent must extract:
1. The JavaScript stack trace from the error boundary
2. Console errors (ReferenceError, TypeError, network fails)
3. Network tab (401/403 to API endpoints, CSP `Refused to load` violations)
4. Cookie inspector (`sessionid` domain scope, JWT presence)

### Likely root cause hypotheses (ranked by fit)

1. **Auth state missing** — Learning MFE shell tries to read user session via cookie/JWT; fails because cross-subdomain cookie scope is broken. If SESSION_COOKIE_DOMAIN contract (filed as P1 follow-up in #1908 + slice-79 agent-2) is misconfigured, this manifests exactly here.
2. **Upstream `frontend-app-learning` library bug** — known class in Ulmo-era Open edX. Would require library version bump in `frontend-app-learning` Dockerfile layer.
3. **CSP violation** — Mereka tenant hosts may not be in `connect-src` or `frame-src` correctly, blocking data fetches.
4. **Plugin slot render failure** — Learning MFE shell imports from `mereka_lms_mfe_slots.py`; if any slot misbehaves the shell may bail. Less likely given other slots are working.

### Sequencing gate

**Do not attempt browser probe until #1906 (Authn fix) is live**. Login currently crashes with `ReferenceError: Can't find variable: getMerekaShellCopy`. Without login, browser can't reach Learning MFE.
