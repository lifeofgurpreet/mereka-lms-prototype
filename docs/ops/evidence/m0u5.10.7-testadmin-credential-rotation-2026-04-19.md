## 1. Exposure Summary

PR #1870 (`d451f2d95`) committed a docs evidence bundle containing a hard-coded test user credential (username: `testadmin`) in plaintext. PR #1871 (`cd5ea3a8a`) redacted the value from the HEAD file, but the credential remains recoverable from the pre-redaction commit in git history.

The value exposed was the shared, well-known test-environment password documented in CLAUDE.md under "Test & Operational Credentials".

Staging (`staging.academyv2.mereka.dev`) was unreachable (connection timeout, HTTP 000) — treated as offline.

3. Stored new value in Infisical:
   - **Path**: `/k8s/mereka-lms`
   - **Key**: `MEREKA_LMS_TESTADMIN_PASSWORD`
   - **Environment**: `dev`
   - **Status**: SECRET CREATED (new key, did not exist previously)
4. Re-synced Django password to match Infisical value (same key retrieved and re-applied)
