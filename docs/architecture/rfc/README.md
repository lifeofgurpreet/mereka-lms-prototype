# Architecture RFCs

This directory holds architecture proposals that are not yet accepted decisions.

## Rules

- RFCs describe candidate future architecture.
- Accepted RFCs should be converted into ADRs or absorbed into living standards.
- Rejected or stale RFCs should move to backlog/issues instead of lingering as active architecture law.
