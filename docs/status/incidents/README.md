# Incident Status
_Status: canonical_

Use this directory for active incident summaries and active recovery tracking that still belongs in the reporting hot path.

Once an incident is cold historical context, move it into `docs/archive/reports/`.

## Start here

| If you need to... | Do this first |
|---|---|
| Publish an active incident update | Start from `docs/guides/standards/STATUS_REPORTING_STANDARD.md`, then place the live note here |
| Check the current state of an active incident | Read the newest incident note in this directory |
| Find supporting proof for an incident claim | Move to `docs/evidence/**` for the relevant evidence pack |
| Find routine weekly or readiness status instead | Use `../weekly/README.md` or `../readiness/README.md` |

## Use this directory for

- active incident summaries
- active recovery tracking
- short-lived incident reporting that still belongs in the hot path

## What this directory is not

- Not the place for durable postmortem evidence. Use `docs/evidence/**`.
- Not the place for general weekly reporting. Use `../weekly/README.md`.
- Not the place for closed historical incident writeups. Move cold material into `docs/archive/**`.
