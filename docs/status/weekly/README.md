# Weekly Status
_Status: canonical_

Use this directory for active weekly program and platform status notes that still matter operationally.

Do not place closed historical reports here. Move those into `docs/archive/reports/` once they are no longer active.

## Start here

| If you need to... | Do this first |
|---|---|
| Publish a new weekly update | Follow `docs/guides/standards/STATUS_REPORTING_STANDARD.md`, then add the note here |
| Find the current weekly operating picture | Read the newest weekly note in this directory |
| Find readiness, migration, or incident-specific status instead | Use `../readiness/README.md`, `../migrations/README.md`, or `../incidents/README.md` |

## Use this directory for

- active weekly status notes that still affect coordination or execution
- weekly snapshots of the docs program or platform posture
- current reporting that belongs in the hot path for operators and contributors

## What this directory is not

- Not a permanent evidence archive. Use `docs/evidence/**` for proof packs.
- Not the place for detailed incident tracking. Use `../incidents/README.md`.
- Not the place for migration-specific status. Use `../migrations/README.md`.
- Not the place for closed history. Move cold material into `docs/archive/**`.
