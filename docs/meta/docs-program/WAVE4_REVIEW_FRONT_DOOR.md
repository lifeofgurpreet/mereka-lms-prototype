## Historical Lane Reading Notes

- `docs/` is the human-facing lane for concepts, runbooks, evidence, review, and archival material.
- `specs/` is the contract lane for normative specs, proposals, plans, and testplans.
- `compatibility` means a wrapper still exists for path stability but is not the canonical truth.
- `generated` means a file is a derived surface and should be edited through its generator.

## Historical Review Questions

- What is canonical truth?
- What is proposal-stage only?
- What is execution planning only?
- What is compatibility-only and still awaiting retirement?
- What is generated and therefore should not be hand-edited?
