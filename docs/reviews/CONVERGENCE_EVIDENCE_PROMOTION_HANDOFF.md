# Convergence Evidence Promotion Handoff

## What This Pack Does

This pack creates the repo-side bridge between the stabilization control board and scattered
Lane A runtime/browser evidence. It promotes durable meta-truth, records contradictions, and
defines the exact proof shape still required before `Stabilization -> Convergence`.

## What It Does Not Do

- It does not fix runtime.
- It does not treat `var/proofs/**` or screenshots as canonical by default.
- It does not claim learner portal closure.
- It does not advance the phase gate.

- local proof is non-canonical unless promoted
- the earlier BFF-401 root-cause claim is contradicted by later local proof
- the program remains blocked in `Stabilization` until a tracked, contradiction-aware runtime bundle exists

- learner secondary-path runtime promotion
