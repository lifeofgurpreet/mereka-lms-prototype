# TTFS Onboarding Reference
_Audience: Platform Operators • Owner: Platform Team • Last verified: 2026-03-10 • Status: canonical_

This reference defines the environment and workflow expectations for TTFS onboarding checks.

## What TTFS means here

TTFS refers to the onboarding funnel and early-user path checks exercised by the `ttfs-onboarding` workflow and related documentation.

## Current operational truth

- The GitHub workflow is `.github/workflows/ttfs-onboarding.yml`.
- This repo treats TTFS as an operator/reporting concern, not a separate product surface.
- Any onboarding walkthrough for humans belongs in [`../../guides/onboarding/README.md`](../../guides/onboarding/README.md).
