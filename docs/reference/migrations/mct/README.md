## ⚠️ CRITICAL: Data Quality Issues Identified

**Updated**: 2025-12-18

### Enrollment Data Quality Problem
Previous migration documentation reported **INCORRECT enrollment numbers** that were heuristically generated using keyword matching instead of real MCT data.

**What was wrong**:
- Reported 57,483 enrollments (FAKE - generated by keyword matching)
- Enrollments assigned by matching user "learning pathway" keywords to course names
- This data was NOT from MCT system

**What is correct**:
- **103,341 real enrollments** extracted from MCT API
- Only **5 of 15 categories** have enrollments (10 categories have zero enrollments)
- Data source: `/api/v3/course/{courseId}/Reports/Users` endpoint

**See `MCT_MIGRATION_STATUS.md` for complete details and corrected statistics.**

## CRITICAL: MCT Structure Mapping

### Platform Limitation
**MCT did not have a proper module/section feature within courses.** Instead, the platform used a flat structure where everything was called a "Course," which created significant confusion during migration planning.

### Workaround Used
The Mereka team used **MCT "Categories"** to represent actual courses, and **MCT "Courses"** to represent what are actually modules/sections within those courses. This is a workaround for MCT's architectural limitation.

### Migration Mapping (VERIFIED ACTUAL COUNTS)

| MCT Entity | Count | Open edX Entity | Description |
|------------|-------|-----------------|-------------|
| **Category** | 15 ✅ | **Course** | Full course/program (e.g., "AI Fluency", "Personal Branding") |
| **Course** | 81 ✅ | **Section/Chapter** | Module within a category (e.g., "Module 1: Introduction") |
| **Lesson** | ~500+ | **Sequential + Vertical + XBlock** | Individual content items (videos, PDFs) |
| **Users** | 69,419 ✅ | **User** | Individual learners |
| **Enrollments** | 103,341 ✅ | **CourseEnrollment** | User enrollments (only 5 categories have enrollments) |

### Key Takeaways

1. **Do NOT create 81 separate Open edX courses** — that would be incorrect
2. **Create 15 Open edX courses** (one per MCT Category) ✅ COMPLETED
3. **Each course contains multiple sections** (from MCT "Courses") ✅ COMPLETED
4. **MCT terminology is confusing** — what MCT calls a "Course" is actually a section/module
5. **Only 5 of 15 categories have enrollments** — 10 categories are content-only with zero enrollments

### Enrollment Reality
**IMPORTANT**: Not all MCT categories have enrollments. The enrollment distribution is:

**Categories WITH enrollments** (5 total):
- Category 22 (Careering as an Administrative Professional): 45,860 enrollments
- Category 27 (Digital Literacy): 45,715 enrollments
- Category 24 (AI Fluency): 10,116 enrollments
- Category 45 (Become an Entrepreneur): 825 enrollments
- Category 46 (Speak with Impact): 825 enrollments

**Categories WITHOUT enrollments** (10 total):
- All other categories (1, 14, 15, 16, 30, 31, 32, 33, 35, 44) have ZERO enrollments
- These are content-only courses with no active learners

For the complete list of 15 courses and their structure, see `MCT_MIGRATION_STATUS.md`.
