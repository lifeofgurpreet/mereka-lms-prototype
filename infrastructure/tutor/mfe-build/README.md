# MFE Build Snapshot

This directory contains a snapshot of the MFE Dockerfile generated by tutor + apply-patches.sh.

## Why this exists

`tutor_env/` is gitignored, so the MFE Dockerfile that drives production image builds has no git
history. Any change to `apply-patches.sh` that affects the MFE build cannot be audited or diffed.
This snapshot is updated after each `apply-patches.sh` run to provide a trackable artifact.

## How to update

```bash
export TUTOR_ROOT="$(pwd)/tutor_env"
tutor config save  # regenerates tutor_env/
./infrastructure/tutor/apply-patches.sh  # applies all patches
cp tutor_env/env/plugins/mfe/build/mfe/Dockerfile infrastructure/tutor/mfe-build/Dockerfile
git add infrastructure/tutor/mfe-build/Dockerfile
git commit -m "chore(mfe): snapshot Dockerfile after apply-patches.sh run"
```
